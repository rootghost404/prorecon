# 2026 Pro-AI Recon Framework

An automated reconnaissance wrapper script for bug hunters built using Bash. It combines the power of Subfinder, AlterX, Httpx, Gau, and Nuclei into a single pipeline.

# Core Language Requirement

golang-go (Go Version 1.20+)

# Recon Tools Required (Must be in system PATH)
subfinder   -> https://github.com/projectdiscovery/subfinder
alterx      -> https://github.com/projectdiscovery/alterx
httpx       -> https://github.com/projectdiscovery/httpx
gau         -> https://github.com/lc/gau
nuclei      -> https://github.com/projectdiscovery/nuclei
